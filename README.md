# SHL Assessment Recommender

## Project Overview

This project is an AI-powered conversational SHL assessment recommendation system built using FastAPI, FAISS, and Sentence Transformers.

The system accepts user queries like:

- backend developer
- .NET developer
- java developer
- software engineer

and recommends relevant SHL assessments using semantic search.

---

## Features

- Conversational API using FastAPI
- Semantic search using FAISS
- Sentence embeddings using Sentence Transformers
- SHL assessment recommendation engine
- Clarification handling
- Refusal handling for unrelated queries

---

## Tech Stack

- Python
- FastAPI
- FAISS
- Sentence Transformers
- NumPy
- Uvicorn
